🤖 Launching Aider - AI Pair Programming

×
⚠️ Privilege Escalation Required Aider requires root or sudo access to modify system files and execute git commands.

Step 1: Open Terminal

SSH to dc1 or open a local terminal session:

ssh dshannon@dc1.cyberinabox.net

Step 2: Escalate to Root (if needed)

For system file modifications:

sudo -i

Or use: su - with root password

Step 3: Navigate to Project Directory

Choose your working directory:

cd /home/dshannon/Documents/CyberHygiene-Project

Step 4: Launch Aider

Start Aider with the local Llama 3.3 70B model:

aider

Configuration auto-loads from ~/.aider.conf.yml (Llama 3.3 70B @ 192.168.1.7)

Step 5: Add Files to Work On

In the Aider prompt, add files:

/add Project_Task_List.md

Common Aider Commands

  • /add <file> - Add file to chat context
  • /drop <file> - Remove file from context
  • /diff - Show pending changes
  • /commit - Commit changes with AI message
  • /undo - Undo last change
  • /help - Show all commands
  • /quit or Ctrl+D - Exit Aider
